# Compensation Drivers in STEM Careers
Statistical exploration of what actually drives salaries in STEM roles.

## Project Overview

There’s a common belief that salary growth in technical careers mainly comes from experience or simply staying longer at a company. I wanted to test that assumption using real data.

This project analyzes a dataset of over **62,000 salary records from the tech industry** to explore how factors like education, experience, and career mobility influence compensation.

The analysis was conducted in **R**, focusing on regression modeling and statistical exploration to better understand which variables appear to matter most.

## What This Project Explores

The main questions behind the analysis were:

- Does earning an advanced degree significantly affect salary?
- How much does experience actually influence earnings?
- Does staying longer at the same company help or slow salary growth?

## Approach

The analysis was performed in R and followed several steps:

1. **Exploratory Data Analysis**
   - Reviewing salary distributions
   - Comparing salaries across education levels
   - Identifying potential outliers

2. **Regression Modeling**
   - Simple regression to examine experience vs salary
   - Multiple regression incorporating education and other variables

3. **Data Transformations**
   - Log transformations were tested to handle skewed salary distributions

The goal was not just to build a model, but to better understand the relationships between these variables.
